## Why this matters

- **A. Logs.** Production (a single VPS) redeploys by recreating the `api` and `web` containers on every push to `main`. Docker deletes a container's logs with it, so after a deploy there's nothing to inspect. We couldn't find out why five Android Spotify sign-ins since 16 October never completed. The old build cache also grows on each deploy (about 5 GB reclaimable as of 2026-11-04).
- **B. Time limit.** New words are generated by validating song candidates in a worker pool. `generateAndDeliverBatch` has a 75-second budget, but it's only checked **between** attempts. A slow pool can keep a learner waiting well past 75 s, and background queue refills have no per-round limit.
- **C. CI.** CI runs web unit tests but not the TypeScript check. `npx tsc --noEmit` passes today, so adding it is free protection. (ESLint currently reports 28 errors, so lint is deliberately left out; see Maintenance notes.)
- **D. Repo.** A 56 MB `harmonix.apk` is tracked in git even though `.gitignore` lists it (lines 65-66). `README.md` says the Play version is 1.0.14 / 17; it's 1.0.17 / 20.

## Steps

### Part A — keep logs, prune build cache

A1. In `coolify-redeploy.sh`, add a function after `log()`:

```bash
LOG_ARCHIVE="${LOG_ARCHIVE:-/home/ubuntu/logs/harmonix}"
archive_container_logs() {
  local name="$1" stamp
  stamp="$(date -u +%Y%m%d-%H%M%S)"
  mkdir -p "$LOG_ARCHIVE"
  if docker inspect "$name" >/dev/null 2>&1; then
    docker logs --timestamps "$name" 2>&1 | gzip > "${LOG_ARCHIVE}/${name}-${stamp}.log.gz" || true
  fi
  find "$LOG_ARCHIVE" -name '*.log.gz' -mtime +30 -delete 2>/dev/null || true
}
```

Call `archive_container_logs "$API"` right before the `run_compose … --force-recreate api` line, and `archive_container_logs "$WEB"` right before the web one.

A2. At the very end of the script, after the final health check succeeds, add `docker builder prune -f --filter until=168h >/dev/null 2>&1 || true` with a `log` line.

**Verify**: `bash -n scripts/coolify-redeploy.sh` → exit 0; `grep -c "archive_container_logs" scripts/coolify-redeploy.sh` → `3`.

### Part B — enforce the time limit inside the pool
