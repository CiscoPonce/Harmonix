# Plan 14-02: Spotify Connect UX (Popup + Library)

## Objective

Deliver seamless Spotify Connect UX on Web: enable popup window OAuth flow so users can authorize Spotify without losing current page state, and add an inline "Connect Spotify" CTA banner inside the empty Library tab.

## Tasks

<task>
  <objective>Implement Popup Window OAuth trigger and postMessage listener on Web</objective>
  <read_first>
    - client/src/lib/spotify.ts
    - client/src/app/settings/page.tsx
    - docs/SPOTIFY-INTEGRATION.md
  </read_first>
  <action>
    Update Spotify connection helper to support popup window OAuth (`window.open('/api/spotify/login', 'spotify_auth', 'width=600,height=720,scrollbars=yes')`). Attach window message listener `window.addEventListener('message', (event) => { if (event.data?.type === 'SPOTIFY_AUTH_SUCCESS') { refreshSpotifyStatus(); } })`. Fallback to standard window.location redirect if popup is blocked by browser.
  </action>
  <acceptance_criteria>
    - `client/src/lib/spotify.ts` (or Settings connect helper) contains `window.open` popup invocation
    - Message listener checks for `SPOTIFY_AUTH_SUCCESS` message type
  </acceptance_criteria>
</task>

<task>
  <objective>Add postMessage auto-close dispatcher in Spotify callback page</objective>
  <read_first>
    - client/src/app/callback/page.tsx
  </read_first>
  <action>
    In `client/src/app/callback/page.tsx`, check if `window.opener` exists upon successful token exchange. If present, dispatch `window.opener.postMessage({ type: 'SPOTIFY_AUTH_SUCCESS' }, '*')` and execute `window.close()`. If `window.opener` is absent, navigate to `/playlists` or `/settings` as standard fallback.
  </action>
  <acceptance_criteria>
    - `client/src/app/callback/page.tsx` contains `window.opener.postMessage` dispatch
    - Callback closes popup window automatically when opened via popup
  </acceptance_criteria>
</task>

<task>
  <objective>Add inline 'Connect Spotify' banner to empty Library tab</objective>
  <read_first>
    - client/src/app/playlists/page.tsx
  </read_first>
  <action>
    In `client/src/app/playlists/page.tsx`, check Spotify connection status. When disconnected or when user has no synced playlists, render a styled inline CTA banner: "Sync your Spotify playlists for personalized lyric learning" with a primary "Connect Spotify" button that invokes the popup OAuth flow.
  </action>
  <acceptance_criteria>
    - `client/src/app/playlists/page.tsx` renders inline "Connect Spotify" banner when disconnected
    - Clicking the banner button triggers the Spotify OAuth popup
  </acceptance_criteria>
</task>
