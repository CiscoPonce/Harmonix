# Plan 14-03: Flutter Settings Language Editors

## Objective

Bring mobile Flutter Settings up to feature parity with Web Settings by adding inline Native Language and Learning (Target) Language selection dropdowns, saving changes directly via Express API preferences endpoint.

## Tasks

<task>
  <objective>Add native and target language pickers to Flutter Settings screen</objective>
  <read_first>
    - mobile/lib/screens/settings_screen.dart
    - mobile/lib/services/api_service.dart
  </read_first>
  <action>
    Update `mobile/lib/screens/settings_screen.dart` to add a 'Learning Profile' section with DropdownButtonFormField controls for Native Language (English, Spanish, French, German, Japanese, Korean, Chinese) and Learning Language. Display current values loaded from auth user profile state.
  </action>
  <acceptance_criteria>
    - `settings_screen.dart` contains dropdown UI for native and learning languages
    - Dropdowns display currently active user language choices
  </acceptance_criteria>
</task>

<task>
  <objective>Wire language preference updates to Express API and refresh word queue</objective>
  <read_first>
    - mobile/lib/services/api_service.dart
    - mobile/lib/screens/settings_screen.dart
  </read_first>
  <action>
    In `mobile/lib/services/api_service.dart`, ensure `updatePreferences({String? nativeLang, String? learningLang})` sends a `PATCH /api/user/preferences` request with JSON body `{ native_language, learning_language }`. Upon HTTP 200 response, update local stored user state and trigger Daily Word cache invalidation so the Learn tab fetches words for the new target language.
  </action>
  <acceptance_criteria>
    - `api_service.dart` sends `PATCH /api/user/preferences` payload with language keys
    - Changing target language in Settings invalidates cached daily word and reloads Learn tab
  </acceptance_criteria>
</task>
