# Plan 14-04: Flutter Spotify Playback (Honest Fallback) & OAuth Deep Link

## Objective

Ship Flutter mobile Spotify integration following locked decisions: use external system browser via `url_launcher` with custom scheme `harmonix://spotify-callback` deep link for OAuth consent, and execute **Honest Fallback** playback UX (30s Deezer preview in-app, explicit "Open in Spotify" button for full tracks).

## Tasks

<task>
  <objective>Configure Android Manifest intent filter for harmonix://spotify-callback deep link</objective>
  <read_first>
    - mobile/android/app/src/main/AndroidManifest.xml
    - mobile/lib/main.dart
  </read_first>
  <action>
    Add an `<intent-filter>` block to `mobile/android/app/src/main/AndroidManifest.xml` under MainActivity:
    `<action android:name="android.intent.action.VIEW" />`, `<category android:name="android.intent.category.DEFAULT" />`, `<category android:name="android.intent.category.BROWSABLE" />`, and `<data android:scheme="harmonix" android:host="spotify-callback" />`.
  </action>
  <acceptance_criteria>
    - `AndroidManifest.xml` contains intent filter with scheme `harmonix` and host `spotify-callback`
  </acceptance_criteria>
</task>

<task>
  <objective>Implement Flutter system browser OAuth trigger and deep link callback handler</objective>
  <read_first>
    - mobile/lib/services/spotify_service.dart
    - mobile/lib/main.dart
  </read_first>
  <action>
    In `mobile/lib/services/spotify_service.dart`, trigger Spotify OAuth using `url_launcher` to open system browser URL `${API_BASE_URL}/api/spotify/login?platform=mobile`. In `main.dart`, listen for incoming app links/deep links (`app_links` or `uni_links` package). When `harmonix://spotify-callback?code={code}` is received, exchange code for user tokens via `POST /api/spotify/callback` and save user state.
  </action>
  <acceptance_criteria>
    - `spotify_service.dart` launches external browser for Spotify OAuth
    - Deep-link listener captures `harmonix://spotify-callback` and updates Spotify connection state
  </acceptance_criteria>
</task>

<task>
  <objective>Implement Honest Fallback playback UX on Flutter playlist detail and player</objective>
  <read_first>
    - mobile/lib/screens/playlist_detail_screen.dart
  </read_first>
  <action>
    On `mobile/lib/screens/playlist_detail_screen.dart`, render 30-second Deezer preview audio controls for in-app listening. Next to each track row and top header, display a prominent "Open in Spotify" button that launches Spotify deep link `spotify:track:{id}` (falling back to web URL `https://open.spotify.com/track/{id}`).
  </action>
  <acceptance_criteria>
    - `playlist_detail_screen.dart` renders "Open in Spotify" deep-link CTA button for tracks
    - Clicking "Open in Spotify" launches external Spotify app or web track page
  </acceptance_criteria>
</task>
