# Plan 18-05: Spotify taste sync and dyslexia font

## Objective

Connected Spotify accounts actually steer song picks, and the dyslexia spacing setting survives a reload on web and exists on Android.

## Work

1. **Taste sync.** After a successful Spotify connect (web OAuth completion and Flutter deep-link success), call the existing `POST /api/user/sync-spotify-profile`. Keep the admin button. Settings Spotify card shows a last-synced time if the profile row has one. Failures must not block “connected” — log and leave the previous cache.
2. **Dyslexia font.** Persist the web toggle (`client/src/app/settings/page.tsx` currently uses `useState(false)` and a document class only). Store it with the other user preferences (`voice_gender` pattern: column or existing preferences JSON — match whatever Settings already saves). Apply `font-dyslexic` on load. Flutter Settings gets the same toggle and applies wider letter spacing on the word card, shelf, and review text. Add the strings to both i18n tables (web already has `dyslexia_font`).

## Done when

- A server or route test covers sync invoked for the connected user (mock Spotify).
- Web: reloading Settings with the preference on keeps the class.
- Flutter: widget test shows the toggle and that study text uses the wider spacing when on.
