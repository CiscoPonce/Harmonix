# Plan 18-03: Library cover fetches

## Objective

Opening Library must not call Deezer once per playlist on every visit.

## Work

`GET /api/playlists` in `server/routes/playlists.js` currently `Promise.all`s `coversForPlaylist` for every playlist, and `coverArtService.js` can hit Deezer when the cache misses.

- List view returns covers already in `song_cache` only (the sync helper, if present).
- Missing covers fill in the background or on playlist detail, not on the list request.
- Detail may still ensure covers, but should batch the cache lookup instead of a sequential HTTP call per song when the row is already cached.

## Done when

A playlist route test shows a list of several playlists with cold Deezer stubs is not called once per playlist when cache rows exist, and `cd server && JWT_SECRET=test JWT_REFRESH_SECRET=test NODE_ENV=test npx mocha 'routes/playlists.test.js' --timeout 20000` exits 0.
