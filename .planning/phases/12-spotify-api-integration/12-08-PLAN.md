## Execution Scope Rationale

This plan is one independently executable web export slice: deterministic validation and cache evidence, a durable ownership-checked mutation job, and the web progress/report consumer. Its 12 files span those inseparable boundaries because the user-visible guarantee—match everything before mutation and restore an honest report—cannot be delivered by a matcher, job table, or dialog alone. Atomic boundaries are Task 1 (pure matcher and corpus), Task 2 (persisted export orchestration/routes), and Task 3 (web initiation/restoration/report), each with an isolated automated gate and no horizontal foundation left without a consuming path.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Harmonix playlist ID → export worker | Client-selected local data reaches provider mutation. |
| Spotify search → match acceptance | Untrusted candidates could be exported as the wrong work. |
| Export worker → Spotify mutation | Rate-limited external side effects may partially complete. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-12-32 | Elevation of Privilege | Source/job ownership | high | mitigate | `req.user.id` prepared ownership queries, 404 non-disclosure, adversarial cross-user tests. |
| T-12-33 | Spoofing | Match identity | high | mitigate | Conservative evidence score, tie/edition rejection, labeled >90% precision gate, no popularity. |
| T-12-34 | Tampering | Duplicate/partial mutation | high | mitigate | Persisted idempotent job, validation-before-create, one create, ordered <=100 batches, per-batch outcomes. |
| T-12-35 | Denial of Service | Search/rate budget | high | mitigate | Cache, low concurrency, per-user gate, exact Retry-After, capped retries, resumable factual state. |
| T-12-36 | Information Disclosure | Report/logs | medium | mitigate | User-owned reports, allowlisted metadata/reasons, redacted provider errors. |
| T-12-37 | Tampering | SQL input | medium | mitigate | Prepared statements for playlist, job, cache, and outcome access. |
</threat_model>
