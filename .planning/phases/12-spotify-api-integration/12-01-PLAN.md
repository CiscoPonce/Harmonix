# Plan 12-01: Spotify Developer App Setup & Environment Configuration

**Status:** Pending  
**Phase:** 12 — Spotify API Integration  
**Milestone:** v1.5

## Objective

Configure Spotify Developer Dashboard application and set up environment variables for local and production deployments.

## Tasks

### 1. Create Spotify Developer Account

- Visit [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)
- Log in with Spotify account (or create one)
- Accept developer terms of service

### 2. Register New Application

- Click "Create app"
- Fill in details:
  - **App name:** Harmonix
  - **App description:** Language learning platform integrating with Spotify for playlist export
  - **Redirect URI:** 
    - Development: `http://localhost:3001/api/spotify/callback`
    - Production: `https://your-domain.com/api/spotify/callback`
  - **Website:** (optional) Your project website
  - Check "Web Playback SDK" if needed (not required for this phase)
- Save and note the **Client ID** and **Client Secret**

### 3. Configure Environment Variables

Create/update `.env` file in server directory:

```bash
# Spotify API Credentials
SPOTIFY_CLIENT_ID=your_client_id_here
SPOTIFY_CLIENT_SECRET=your_client_secret_here
SPOTIFY_REDIRECT_URI=http://localhost:3001/api/spotify/callback

# Production (update when deploying)
# SPOTIFY_REDIRECT_URI=https://your-domain.com/api/spotify/callback
```

### 4. Update .env.example

Add Spotify variables to `.env.example` for documentation:

```bash
# Spotify API (Phase 12)
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
SPOTIFY_REDIRECT_URI=
```

### 5. Test API Credentials

Create a simple test script to verify credentials:

```bash
node scripts/test-spotify-auth.js
```

Expected output: Valid access token received from Spotify.

## Success Criteria

- [ ] Spotify Developer App created and active
- [ ] Client ID and Secret stored securely in `.env`
- [ ] Redirect URI configured correctly
- [ ] `.env.example` updated with Spotify variables
- [ ] Test script successfully obtains access token

## Dependencies

- None (this is a setup task)

## Estimated Time

30 minutes

## Notes

- Never commit `.env` file with real credentials to Git
- Rotate credentials immediately if accidentally exposed
- Spotify allows multiple redirect URIs; add both dev and prod URLs
- Keep Client Secret confidential; it's used only server-side
