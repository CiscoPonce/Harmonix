## Trust Boundaries

| Boundary | Description |
|---|---|
| System browser → Android App Link | External HTTPS navigation attempts to influence in-app routing. |
| Flutter → Express | Bearer-authenticated app requests provider actions and data. |
| Provider DTO → url_launcher/widgets | Untrusted URLs/text enter native rendering and external launch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-12-22 | Spoofing | Android OAuth completion | high | mitigate | Verified App Link host/path, matching assetlinks fingerprint, fixed backend redirect, and one-shot route tests. |
| T-12-23 | Information Disclosure | Mobile storage | high | mitigate | ApiClient stores only Harmonix tokens; provider credentials remain backend-only and tests inspect storage calls. |
| T-12-24 | Spoofing | External URL launch | high | mitigate | Allowlist backend authorization host and API-provided Spotify HTTPS links; reject unknown schemes/hosts. |
| T-12-25 | Denial of Service | Refresh/rate UI | medium | mitigate | Disable duplicate actions, honor retryAfterSec, and preserve content without loops. |
| T-12-26 | Information Disclosure | Disconnect residue | high | mitigate | Remove rendered provider state only after backend transactional cleanup succeeds. |
</threat_model>
