<task type="auto">
 <name>Task 2: Quiz Generator Service</name>
 <files>server/services/quizGenerator.js, server/services/quizGenerator.test.js</files>
 <action>
 Create `server/services/quizGenerator.js` that:
 1. Exports `generateQuiz(songId, mappedVocab, unmappedVocab, lyricsLines)`
 2. Uses NVIDIA NIM (openai SDK) to generate 5-10 fill-in-the-blank questions.
 3. Each question: { "id", "blanks" (array of {vocab_id, blank_text}), "options" (4 choices), "correct_vocab_id", "context" }
 4. Prompt instructs AI to use the provided vocabulary words and create natural blanks in lyric snippets.
 5. Write unit tests mocking the AI call.
 </action>
 <verify>
 <automated>npm --prefix server test server/services/quizGenerator.test.js</automated>
 </verify>
 <done>Quiz generator produces structured quiz data.</done>
</task>

<task type="auto">
 <name>Task 3: Study API Routes</name>
 <files>server/routes/study.js, server/routes/study.test.js, server/index.js</files>
 <action>
 1. Create `server/routes/study.js` with endpoints:
    - POST /api/study/:songId/start → creates quiz_session, returns session_id + questions
    - POST /api/study/:sessionId/answer → records answer, returns { correct, feedback }
    - GET /api/study/:sessionId/result → returns score + breakdown

 3. Mount router in `server/index.js` at `/api/study`.
 4. Write tests for start, answer, and result flows.
