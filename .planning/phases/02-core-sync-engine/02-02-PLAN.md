  <files>client/src/hooks/useSyncEngine.ts</files>
  <action>

    - Inside the loop, call `parser.play(adjustedTimeMs)`.

    - Implement `latencyCompensationMs` as a parameter (per Checker feedback, use -150ms default).
    - Use `onPlay` callback of the parser to update a local `currentLineIndex` state.
    - Handle cleanup of the animation frame on unmount.
  </action>
  <verify>

  </verify>
  <done>Sync loop is implemented with latency compensation to prevent drift.</done>
