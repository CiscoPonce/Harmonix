  <name>Task 2: Implement Auth Logic & Middleware</name>
  <files>server/auth.js</files>
  <behavior>
    - `hashPassword(password)`: Returns bcrypt hash.
    - `comparePassword(password, hash)`: Returns boolean.
    - `generateAccessToken(user)`: Returns JWT signed with `JWT_SECRET` (15m expiry).
    - `generateRefreshToken(user)`: Returns JWT signed with `JWT_REFRESH_SECRET` (7d expiry).
    - `verifyAccessToken(token)`: Returns payload or throws error.
    - `verifyRefreshToken(token)`: Returns payload or throws error.
  </behavior>
  <action>
    Implement JWT split-token logic using `jsonwebtoken` and `bcryptjs`. Ensure robust error handling for token expiration and invalid signatures.
  </action>

<task type="auto">
  <name>Task 3: Implement Auth Endpoints</name>
  <files>server/index.js</files>
  <action>
    - Setup Express server with `json`, `cookie-parser`, and `cors` (allow credentials, origin http://localhost:3000).
    - POST `/api/auth/register`: 
      - Validate email/password presence.
      - Check for existing email; return 409 Conflict if found.
      - Hash password, store user, return 201 Created.
    - POST `/api/auth/login`: 
      - Find user by email.
      - Compare passwords; return 401 Unauthorized if mismatch or user not found.
      - Generate tokens, set refresh token in HttpOnly cookie, return access token in JSON body.
    - POST `/api/auth/refresh`: Verify refresh cookie, generate new tokens, update cookie, return new access token.
    - GET `/api/auth/me`: Protected route using access token, returns user object (minus password).
    - POST `/api/auth/logout`: Clear refresh token cookie.
  </action>
  <verify>
    <automated>
      # Start server in background
      PORT=3001 node server/index.js & sleep 2;
      # Test Registration
      curl -s -X POST -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123"}' http://localhost:3001/api/auth/register | grep -q "201" || echo "Registration success";
      # Test Duplicate Registration (Expect 409)
      curl -s -o /dev/null -w "%{http_code}" -X POST -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123"}' http://localhost:3001/api/auth/register | grep -q "409";
      # Test Login (Expect 200)
      curl -s -i -X POST -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123"}' http://localhost:3001/api/auth/login | grep -q "200";

    </automated>
