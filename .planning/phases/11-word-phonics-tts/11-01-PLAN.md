2. **Create server/services/ttsDaemon.js** — A singleton module managing the Pocket-TTS HTTP server process:
   - Export an object with: `start(language)`, `stop()`, `restart(language)`, `healthCheck()`, and a `currentLanguage` property
   - `start(language)` uses `child_process.spawn` to run: `pocket-tts serve --host 127.0.0.1 --port 3002 --language <language>`
   - Set `{ stdio: "pipe" }` on spawn. Monitor `child.stderr` for a readiness string (e.g., "Uvicorn running" or "Application startup complete") to set an internal ready flag
   - `stop()` sends SIGTERM to the child process, waits up to 3 seconds, then SIGKILL if needed. Set ready=false
   - `restart(language)` calls stop() then start(language). Store the target language in `this.currentLanguage`
   - `healthCheck()` does `fetch("http://127.0.0.1:3002/health")` and returns `res.ok`. Catches errors and returns false
   - Track the child process reference and ready state as instance properties

3. **Create server/services/ttsService.js** — The core pronunciation service:
   - Import `db` from `../db` and `ttsDaemon` from `./ttsDaemon`
   - Define `VOICE_MAP` constant: `{ es: "lola", fr: "estelle", de: "juergen", pt: "rafael", en: "alba", it: "giovanni" }`
     IMPORTANT: D-11-03 specified helena/brasil/amy/fiamma for de/pt/en/it, but these voice names do NOT exist in Pocket-TTS (confirmed by cross-referencing pocket-tts source `_ORIGINS_OF_PREDEFINED_VOICES`). Using corrected names from RESEARCH.md to prevent HTTP 400 errors.
   - Define `SUPPORTED_LANGUAGES` = `Object.keys(VOICE_MAP)` (the 2-letter codes: es, fr, de, pt, en, it)
   - Implement `padWavWithSilence(wavBuffer, sampleRate = 24000, silenceSeconds = 1)`:
     WAV header is 44 bytes. Calculate silence bytes as `sampleRate * silenceSeconds * 2` (16-bit mono). Allocate a zero-filled silence Buffer. Extract PCM data from wavBuffer subarray starting at offset 44. Concatenate: silence + pcmData + silence. Build result buffer: copy original 44-byte header, then padded PCM. Update WAV header fields: chunk size at offset 4 (result.length - 8 as UInt32LE), data size at offset 40 (paddedPcm.length as UInt32LE). Return the result Buffer.
   - Implement `getCachedPronunciation(word)` — `db.prepare("SELECT audio_blob FROM word_pronunciation_cache WHERE word = ?").get(word)` — returns Buffer or undefined
   - Implement `cachePronunciation(word, audioBlob)` — `db.prepare("INSERT OR IGNORE INTO word_pronunciation_cache (word, audio_blob) VALUES (?, ?)").run(word, audioBlob)`
   - Implement `fetchFromPocketTTS(word, voiceUrl)` — POST to `http://127.0.0.1:3002/tts` with `Content-Type: application/x-www-form-urlencoded` body: `text=<word>&voice_url=<voiceUrl>`. Return the response ArrayBuffer as a Buffer. Throw with code `tts_generation_failed` if response is not ok.
   - Implement `getPronunciationForWord(word, langCode)`:
     a. If `!SUPPORTED_LANGUAGES.includes(langCode)`, throw with code `unsupported_language`
     b. Check cache: `getCachedPronunciation(word)` — if hit, return the cached Buffer
     c. Ensure daemon is running for correct language: if `ttsDaemon.currentLanguage !== langCode`, call `await ttsDaemon.restart(langCode)` and wait for health check (retry up to 5 times with 1s delay)
     d. Fetch from Pocket-TTS: `fetchFromPocketTTS(word, VOICE_MAP[langCode])`
     e. Pad with silence: `padWavWithSilence(wavBuffer)`
     f. Cache: `cachePronunciation(word, padded)`
     g. Return padded Buffer
   - Implement `preCachePronunciation(word, langCode)` — wraps `getPronunciationForWord` in try/catch, swallows all errors (fire-and-forget)
   - Export: `{ VOICE_MAP, SUPPORTED_LANGUAGES, padWavWithSilence, getPronunciationForWord, preCachePronunciation, getCachedPronunciation }`

4. **Server startup hook** — In server/index.js, after the existing imports (around line 18, after `require('dotenv').config()`), add:
