**Phase:** 19 — Account profile, photo, and achievements

## Goal

Finish the Account Profile experience across Web, Android, and Play Store / Privacy compliance by:
1. Localizing the 5 active achievement titles and descriptions across all 6 supported UI languages (`en`, `es`, `fr`, `de`, `pt`, `it`) on Web and Android.

## Step 3 — Self-Service Account Deletion (`DELETE /api/user/account`) & Privacy/Play Store Alignment

1. **Server (`server/services/profileService.js` & `server/routes/profile.js`):**
   - Implement `deleteAccount(userId)` inside a single SQLite transaction that removes all user-owned rows in dependency order:
     - `quiz_answers` (where `session_id IN (SELECT id FROM quiz_sessions WHERE user_id = ?)`)
     - `quiz_sessions`
     - `playlist_songs` (where `playlist_id IN (SELECT id FROM playlists WHERE user_id = ?)`)
     - `playlists`
     - `user_avatars`
     - `user_badges`
     - `user_vocab_progress`
     - `user_stats`
     - `daily_words`
     - `user_word_queue`
     - `user_queue_refill`
     - `user_spotify_profiles`
     - `spotify_oauth_transactions`
     - `user_spotify_tokens`
     - `user_spotify_playlists`
     - `spotify_export_jobs`
     - `shared_postcards` (`UPDATE shared_postcards SET user_id = NULL WHERE user_id = ?` so shared public postcards remain valid without dangling FK, or delete if owned)
     - `usage_events` (`UPDATE usage_events SET user_id = NULL WHERE user_id = ?`)
     - `users` (`DELETE FROM users WHERE id = ?`)
   - Return `true` when the user row was deleted, `false` when not found.
   - Expose `DELETE /api/user/account` on `server/routes/profile.js`: clears the `refreshToken` cookie and returns `204` (or `404` if user no longer exists).
   - Add unit tests in `server/services/profileService.test.js` and route integration tests in `server/routes/profile.test.js`.
2. **Web (`client/src/app/settings/page.tsx`) & Android (`mobile/lib/services/api_client.dart`, `mobile/lib/screens/settings_screen.dart`):**
   - Add `deleteAccount()` to `ApiClient` on Android.
   - Add a Danger Zone / Delete Account button at the bottom of the Account screen on both Web and Android with a confirmation step before calling `DELETE /api/user/account` and signing out.
   - Add widget test coverage in `mobile/test/account_profile_test.dart`.
3. **Privacy Policy & Play Console Documentation (`client/src/app/privacy/page.tsx`, `docs/PLAY-CONSOLE-LISTING.md`, `README.md`):**
   - Update `/privacy` to mention optional username, short bio, and optional account photo (stored privately in SQLite, never shared publicly or sold, removable anytime) and document in-app account deletion alongside email support.
   - Update `docs/PLAY-CONSOLE-LISTING.md` and `README.md` to reflect `1.0.20 (23)`, optional account photo disclosure, and in-app + email account deletion.
